infin — LOGO KIT
================================================

Wordmark: in/fin  ·  Typeface: Space Grotesk (SemiBold 600 letters, Regular 400 slash)
Palette (monochrome):
  Ink    #14130F      Paper  #F4F3F0
  Slate  #6B655B      Stone  #B5AEA2   (slash accent)

--------------------------------------------------
FOLDERS
  /svg   Vector logos — transparent, scalable, editable. Use for print, web and master artwork.
  /png   High-resolution raster exports on their intended background. Use for quick placement.

--------------------------------------------------
FILES & WHEN TO USE
  wordmark-ink        Primary. Dark wordmark — for light backgrounds.
  wordmark-paper      Reverse. Light wordmark — for dark backgrounds.
  wordmark-black      One-colour solid black (slash same weight).
  wordmark-white      One-colour solid white.
  lockup-ink/paper    Wordmark + "DIGITAL STUDIO" descriptor.
  badge-square-*      App icon / avatar — rounded square (in/ mark).
  badge-circle-*      Circular avatar (in/ mark).
  favicon             16–48px browser/app icon.

--------------------------------------------------
RULES
  • Minimum width: 96px digital / 22mm print (wordmark). Use the badge below 96px.
  • Clear space = the cap-height of the wordmark on all sides.
  • Never recolour, re-typeset, skew, outline or add effects.
  • The SVGs reference Space Grotesk via web import; when outlining to paths in
    Illustrator, convert text to outlines to lock the letterforms.
