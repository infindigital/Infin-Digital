# IMAGE REPLACEMENT GUIDE

Every image that renders on the live INFIN Digital website, listed so that images can be
swapped without reading any code.

**Scope:** the five live routes only (`/`, `/about`, `/services`, `/work`, `/contact`) plus the
shared header and footer. The theme ships dozens of demo routes that are not part of this site and
are excluded here, and are blocked from indexing in `public/robots.txt`.

- **135 image slots** across the site, using **109 unique files**
- **68 are HIGH priority**: template stock that shows fake people, fake client logos, or fake
  project work, and should not go live as is
- **40 MEDIUM**, **22 LOW**, **5 keep as is**

## How to replace an image

1. Find the row below for the image you want to change.
2. Put your new file in the same folder as **Current path**, using the same file extension.
3. Either overwrite the existing file name, or add a new file and update the `src` in the file named
   under **Section**. All section files live in `src/shared/sections/`.
4. Match the **Source W x H** as closely as you can. Matching the ratio matters more than matching
   the exact pixels, because a different ratio will change the layout.
5. Update the `alt` attribute at the same time. The **Alt text** column tells you what is there now.

All paths are relative to the `public/` folder, so `/assets/imgs/pages/img-28.webp` lives at
`public/assets/imgs/pages/img-28.webp`.

## Column meanings

| Column | Meaning |
|---|---|
| Section | The visible section, and the source file that renders it |
| Display W x H | The `width` and `height` attributes in the markup. `fluid` means CSS controls the size, `fills container` means it is a CSS background |
| Source W x H | The real pixel size of the file on disk right now. Aim for this or larger |
| Ratio | Aspect ratio of the current file. Keep this the same to avoid layout shift |
| Alt text | The alt text currently in the code. `PLACEHOLDER` means it must be rewritten |
| Priority | HIGH means it misrepresents the business today and must be replaced before launch |

## Formats

- Photographs: WebP preferred, JPG acceptable. Quality 80 to 85 is usually indistinguishable from
  the original at a fraction of the weight.
- Logos and icons: SVG preferred, transparent PNG otherwise.
- Background video: **.mp4 (H.264)**. The current `live-bg.mov` will not autoplay in Chrome, so most
  visitors see the still fallback instead of the video.
- Keep individual photographs under about 300 KB. Several files in `/assets/imgs/pages/` are over
  1.5 MB, which is the single biggest page speed problem on the site today.

## The honesty problem, read this first

The theme shipped with stock imagery of people who are not your team, logos of companies who are not
your clients, and screenshots of projects that were never built. Copy has been rewritten so that
nothing in text claims these are real. **The images still show them.** Until they are replaced, the
site implies client relationships and a team that do not exist.

The HIGH priority rows are exactly these. In order of how badly they misrepresent the business:

1. **Client and partner logos** (`brand-1` to `brand-6`, `logo-brand-01` to `logo-brand-06`) shown in
   a "trusted by" strip. These are invented companies.
2. **Portfolio project images** on `/work` and the homepage. These are template mockups.
3. **Avatars and headshots** on the testimonial, team and contact sections. These are stock faces.
4. **Award badges** on the homepage and `/about`. There are no awards behind them.

If you do not have replacements for a whole group yet, removing that section is more honest than
leaving the placeholder. See CONTENT-REPLACEMENT-GUIDE.md for which sections that means.
